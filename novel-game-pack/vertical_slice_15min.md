# 15 分钟垂直切片：哈利·波特第一册题材

## 目标

- 平台：Web。
- 形态：文字叙事 + 插画 + 轻调查。
- 时长：12—18 分钟。
- 玩家身份：霍格沃茨一年级新生，原创角色。
- 时间：开学第一周。
- 原则：不逐段复演原著主线，玩家经历一个可以自然嵌入第一册世界的原创事件。

## 游戏命题

玩家发现一幅会移动的肖像在每次提到三楼走廊时都会消失。报告老师可以换取安全感与学院分；隐瞒调查可以得到真相与秘密；保护肖像则可能失去自己的信誉。

核心价值冲突：

```text
真相 vs. 安全
学院认可 vs. 对个体的承诺
好奇心 vs. 尊重他人秘密
```

## 三个核心动词

```text
观察
询问
承诺
```

## 资源

不使用单一“好感度”进度条。建议：

```text
TIME_SLOTS: 9 个时段
HOUSE_POINTS: 学院分
PORTRAIT_TRUST: 肖像信任
TEACHER_SUSPICION: 教师怀疑
KNOWLEDGE_FLAGS: 玩家实际知道的线索
PROMISE_LEDGER: 答应过谁、欠了谁
```

每个时段只能访问一个地点。访问图书馆会失去调查走廊的机会；替肖像保守秘密会增加信任，但降低向教师说明情况的信誉。

## 场景结构

### 场景 1：公共休息室，2 分钟

功能：建立玩家身份、学院归属和第一个异常。

事件：

- 开学第一周，玩家听见高年级学生谈论三楼走廊禁令。
- 墙上肖像听到“三楼”后消失，只留下一枚画框背面的铜扣。
- 玩家可以选择捡起铜扣、告诉级长或假装没看见。

第一个有代价的选择：

- 捡铜扣：获得物证，增加教师怀疑。
- 告诉级长：增加学院分，肖像信任下降。
- 假装没看见：保留自由时间，但错过第一条线索。

### 场景 2：图书馆，3 分钟

功能：知识、规则和错误信息。

事件：

- 玩家查校史、走廊平面图和肖像名录。
- 图书管理员只提供公开信息。
- 另一名新生给出不可靠传闻。
- 玩家必须判断“事实、传闻、猜测”。

选择：

- 查校史：获得制度背景，耗时两个时段。
- 问同学：获得快线索，但可能被误导。
- 跟踪画像：进入走廊，风险上升。

### 场景 3：魔药课教室或走廊，3 分钟

功能：权威压力与关系取舍。

事件：

- 教授追问铜扣来源。
- 玩家可以如实说明、替同学掩护或部分隐瞒。
- 走廊里出现肖像留下的第二个痕迹。

关键机制：

- 把全部线索交给教授会增加教师信任，但肖像拒绝继续交流。
- 完全隐瞒会获得肖像信任，但一旦被发现，学院分和信誉同时受损。

### 场景 4：禁入走廊门口，3 分钟

功能：核心真相与不可逆选择。

真相：

- 肖像不是失踪，而是在保护一幅被错误挂在禁入区边缘的旧画。
- 它每次消失，是为了躲避不该听见禁令的人，而不是因为走廊里一定有怪物。
- 传闻把“安全制度”误读成了“怪物藏身处”。

选择：

- 报告完整真相：获得教师认可，肖像被重新安置，但玩家失去一个秘密盟友。
- 帮助肖像转移：保留秘密，违反校规，获得肖像信任和隐藏线索。
- 公开传播：学院内名声上升，但事实被扭曲，教师怀疑上升。

### 场景 5：收束，2 分钟

根据状态进入三个结局：

#### 结局 A：值得信任的新生

- 玩家如实说明并保护肖像的隐私。
- 获得学院分与教授认可。
- 肖像愿意在未来提供一次帮助。

#### 结局 B：守密者

- 玩家帮助肖像转移，承担扣分。
- 肖像成为长期秘密信息来源。
- 玩家获得隐藏成就“画框之后”。

#### 结局 C：传闻制造者

- 玩家公开部分真相，名声上升但事实失真。
- 肖像不再信任玩家。
- 教师开始怀疑玩家卷入禁入区域。

## 为什么这适合第一册

- 保留城堡、学院、规则、画像和教师权威。
- 不改变原著主线，不提前揭露魔法石。
- 让玩家面对“规则是否总等于正确”的第一册主题。
- 通过一个独立小事件让世界观、人物和玩法咬合。

## 最小资产清单

- 背景 4 张：公共休息室、图书馆、走廊、禁入区门口。
- 肖像 3 张：正常、消失前、重新出现。
- 角色头像 4 张：玩家、同学、教授、级长。
- UI 图标 12 个：时间、学院分、秘密、承诺、存档等。
- 环境音 4 条：壁炉、图书馆、走廊风、远处课堂。
- 音效 8 条：画像移动、脚步、翻书、铜扣、提示、选择、结局、成就。

## 实现建议

### 第一版

- React 或纯 HTML。
- Ink/inkjs 管剧情。
- 本地存储管存档。
- 背景和肖像先用占位图。

### 第二版

- 加轻微场景过渡和画像动画。
- 加自动播放和文本速度设置。
- 加路线回顾，不显示未解锁秘密。
- 加 3 个成就和路径覆盖测试。

## 验收

- 首次选择在 90 秒内出现。
- 三个结局均可达。
- 每个结局至少回收两个前置选择。
- 没有死路。
- 玩家重玩时能发现至少一处新因果。
